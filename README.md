# C-- Compiler

A compiler written in **C** that translates a C-like programming language into C-- intermediate code and assembly.

## Overview

This project was developed as part of my study of compiler construction and explores the major stages of a compiler pipeline.

### Technologies

* C
* Lex
* Yacc
* Assembly
* Linux
* Make

### Concepts Demonstrated

* Lexical analysis
* Parsing
* Abstract syntax / intermediate representations
* Symbol tables
* Code generation
* Assembly generation
* Compiler architecture

## What I Learned

This project gave me practical experience working with lower-level programming concepts and helped strengthen my understanding of how programming languages are translated from source code into executable representations.
